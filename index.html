High Availability Web Architecture on AWS

This project simulates a real-world Fintech scenario where a web application must remain highly available, resilient and capable of validating instance health automatically.

Technologies Used

  • AWS
  • Terraform
  • Docker
  • Application Load Balancer
  • Amazon EC2
  • Amazon ECR
  • NAT Gateway

Main Features

  • High Availability Architecture
  • Private EC2 Instances
  • Automatic Health Checks
  • Secure Outbound Internet Access
  • Docker Container Deployment

Infrastructure deployed using Terraform and Docker containers hosted in Amazon ECR.
